+================================================================================================+
|                                       PFPF                                                     |
|                            (Packet File Process Flow)                                          |
+================================================================================================+

                                         |
                                         v

+------------------------------------------------------------------------------------------------+
|                                  0) PCAP GLOBAL HEADER (24 Bytes)                              |
+------------------------------------------------------------------------------------------------+
| Read once                                                                                      |
|                                                                                                |
|  +-------------------+                                                                         |
|  | Magic Number      | ---> Detect Endianness (Little / Big)                                   |
|  +-------------------+                                                                         |
|  | Version Major     |                                                                         |
|  | Version Minor     |                                                                         |
|  | Snaplen           | ---> Maximum captured packet size                                       |
|  | Network           | ---> Link Layer Type                                                    |
|  +-------------------+                                                                         |
|                                                                                                |
| Example:                                                                                       |
|     LINKTYPE_ETHERNET = 1                                                                      |
|     LINKTYPE_LINUX_SLL2 = 276                                                                  |
+------------------------------------------------------------------------------------------------+

                                         |
                                         |
                                         v

+================================================================================================+
|                              PACKET PROCESSING LOOP                                             |
|                                  while(!EOF)                                                    |
+================================================================================================+

                                         |
                                         v


+------------------------------------------------------------------------------------------------+
|                         1) PCAP PACKET HEADER (16 Bytes)                                       |
+------------------------------------------------------------------------------------------------+
| Read:                                                                                          |
|                                                                                                |
|  timestamp_seconds                                                                             |
|  timestamp_microseconds                                                                        |
|  incl_len  ------------------------------+                                                     |
|  orig_len                                |                                                     |
|                                          |                                                     |
|                                          v                                                     |
|                              Number of captured bytes                                          |
|                              belonging to this packet                                          |
+------------------------------------------------------------------------------------------------+

                                           |
                                           |
                                           v


+================================================================================================+
|                            2) CAPTURED PACKET DATA                                             |
|                            (length = incl_len bytes)                                           |
+================================================================================================+

                                           |
                                           |
                                           v


+------------------------------------------------------------------------------------------------+
|                             3) DATA LINK LAYER                                                 |
|                             Depends on LINKTYPE                                                |
+------------------------------------------------------------------------------------------------+

        Example:
        
        LINKTYPE_LINUX_SLL2

+------------------------------------------------------------------------------------------------+
|                         Linux SLL2 Header (20 Bytes)                                           |
+------------------------------------------------------------------------------------------------+
|                                                                                                |
|  Protocol Type                                                                                 |
|       |                                                                                        |
|       +---------------------> 0x0800 = IPv4                                                    |
|                                                                                                |
|  Interface Index                                                                               |
|  ARPHRD Type                                                                                   |
|  Packet Type                                                                                   |
|  Address                                                                                       |
|                                                                                                |
+------------------------------------------------------------------------------------------------+

                                         |
                                         |
                                         v


+------------------------------------------------------------------------------------------------+
|                              4) NETWORK LAYER                                                  |
|                                  IPv4 Header                                                   |
+------------------------------------------------------------------------------------------------+
| Read minimum header first (20 Bytes)                                                           |
|                                                                                                |
| Fields:                                                                                        |
|                                                                                                |
| Version                                                                                        |
| IHL  ----------------------------+                                                             |
|                                  |                                                             |
|                                  v                                                             |
|                       Real Header Length = IHL * 4                                             |
|                                                                                                |
| Total Length                                                                                   |
| Source IP                                                                                      |
| Destination IP                                                                                 |
| Protocol --------------------------+                                                           |
|                                    |                                                           |
|                                    v                                                           |
|                                 6 = TCP                                                        |
|                                17 = UDP                                                       |
|                                 1 = ICMP                                                       |
+------------------------------------------------------------------------------------------------+

                                         |
                                         |
                                         v


+------------------------------------------------------------------------------------------------+
|                         5) TRANSPORT LAYER                                                     |
|                             TCP Header                                                         |
+------------------------------------------------------------------------------------------------+
| Read minimum TCP header (20 Bytes)                                                             |
|                                                                                                |
| Fields:                                                                                        |
|                                                                                                |
| Source Port                                                                                    |
| Destination Port                                                                               |
| Sequence Number                                                                                |
| ACK Number                                                                                     |
| Data Offset ----------------------+                                                            |
|                                   |                                                            |
|                                   v                                                            |
|                         TCP Header Length = Offset * 4                                         |
|                                                                                                |
| Flags:                                                                                         |
| SYN FIN ACK RST PSH URG                                                                        |
|                                                                                                |
+------------------------------------------------------------------------------------------------+

                                         |
                                         |
                                         v


+================================================================================================+
|                         6) APPLICATION DATA / PAYLOAD                                          |
+================================================================================================+
| Remaining bytes:                                                                               |
|                                                                                                |
| payload_length =                                                                               |
|                                                                                                |
| incl_len - (SLL2 + IP Header + TCP Header)                                                     |
|                                                                                                |
| Examples:                                                                                      |
|                                                                                                |
| HTTP                                                                                           |
| TLS                                                                                            |
| DNS                                                                                            |
| SSH                                                                                            |
| Custom Protocol                                                                                |
+================================================================================================+

                                         |
                                         |
                                         v


+------------------------------------------------------------------------------------------------+
|                         7) MOVE TO NEXT PACKET                                                 |
+------------------------------------------------------------------------------------------------+

Instead of reading payload:

        fseek()

or:

        pointer += remaining_bytes


Now:

fp points to:

        +---------------------------+
        | Next Packet Header 16B    |
        +---------------------------+

                                         |
                                         v

                                  Repeat until EOF
